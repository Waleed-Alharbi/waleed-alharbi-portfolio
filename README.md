# Waleed Alharbi — Portfolio

A bilingual editorial portfolio for Waleed Alharbi, built from scratch with React, TypeScript, Vite, Framer Motion, and custom CSS.

## Local development

```powershell
npm install
npm run dev -- --host 0.0.0.0
```

## Verification

```powershell
npm run typecheck
npm run lint
npm run build
```

## Structure

- `src/sections` — homepage narrative sections
- `src/pages` — homepage and project case-study routes
- `src/data` — verified profile and project data
- `src/i18n` — English and Arabic interface content
- `src/assets` — supplied personal imagery and real project screenshots
- `src/styles` — custom responsive editorial design system
- `scripts` — reproducible optimization and browser-capture helpers
- `screenshots` — required local visual review captures

The supplied source images remain untouched. One-time WebP derivatives are used in the browser for the two largest PNG photographs.
